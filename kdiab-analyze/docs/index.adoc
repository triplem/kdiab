:toc: left
:icons: font

Welcome to the kdiab-analyze documentation hub.
`kdiab-analyze` is a stateless Backend-for-Frontend that aggregates health data from
`kdiab-measures`, `kdiab-profiles`, and `kdiab-treatments` and computes clinical analytics
(timeline, HbA1c, AGP) for the unified frontend.
