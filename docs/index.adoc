= kdiab Platform Documentation
:toc: left
:icons: font

*kdiab* is a Type 1 Diabetes (T1D) management platform consisting of four services hosted in a single monorepo.

== Services

[cols="1,3"]
|===
| Service | Description

| link:../measures/index.html[kdiab-measures]
| Health measurement tracking — CGM, BGM, blood pressure, weight, pulse

| link:../profiles/index.html[kdiab-profiles]
| Insulin pump basal profile management

| link:../treatments/index.html[kdiab-treatments]
| Treatment event tracking — bolus, basal, carbs, corrections

| kdiab-analyze
| Stateless Backend-for-Frontend: aggregates data from all three services and provides a unified analytics dashboard (timeline, HbA1c, AGP, profiles)
|===
