= kdiab Platform Documentation
:toc: left
:icons: font

*kdiab* is a Type 1 Diabetes (T1D) management platform — a monorepo of nine backend services plus a shared library and a React frontend.

== Services

[cols="1,3"]
|===
| Service | Description

| link:../measures/index.html[kdiab-measures]
| Health measurement tracking — CGM, BGM, blood pressure, weight, pulse

| link:../profiles/index.html[kdiab-profiles]
| Insulin pump basal profile management

| link:../treatments/index.html[kdiab-treatments]
| Treatment event tracking — bolus, basal, carbs, corrections

| link:../analyze/index.html[kdiab-analyze]
| Stateless Backend-for-Frontend: aggregates data and computes analytics (timeline, HbA1c, AGP)

| link:../users/index.html[kdiab-users]
| User lifecycle, settings, and doctor–patient relationship management

| link:../carbs/index.html[kdiab-carbs]
| Food / carbohydrate database and entry tracking

| link:../calc/index.html[kdiab-calc]
| Stateless dose calculator: bolus recommendation from profile + CGM trend

| link:../nightscout/index.html[kdiab-nightscout]
| Nightscout API v3 compatibility layer for AAPS, xDrip+, Juggluco — v1 retained for backward compatibility (optional service)
|===
