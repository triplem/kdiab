= kdiab Platform — Architecture Decision Records
:toc: left
:icons: font

All ADRs for the kdiab platform are consolidated here.
Platform-wide ADRs are numbered ADR-001–ADR-099.
Service ADRs use a `ADR-{SVC}-NNN` prefix (e.g. `ADR-MEA-`, `ADR-PRO-`, `ADR-TRE-`, `ADR-ANA-`, `ADR-NSC-`, `ADR-USR-`).
Within each service the three-digit number groups by concern: 1xx = tooling, 2xx = domain, 3xx = infrastructure.
