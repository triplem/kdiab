== Overview

This document covers edge cases that automated Playwright tests cannot reliably reproduce:
OS-locale date formats, mobile viewport layouts, OIDC session lifecycle, and cross-browser divergence.

Run this checklist before every release candidate. Estimated time: *≤ 30 minutes*.

Test accounts (password `password` for all):

| `mike` | PATIENT | glucose unit mmol/L
| `dr_house` | DOCTOR | assigned to sarah
| `admin` | ADMIN | —
|===

Stack must be running: `docker compose up` (or `./podman-up.sh`).

== 2. Date / Time Input Formatting

The date-time inputs in Add Treatment and Add Measure use `type="text"` with a `dd.MM.yyyy HH:mm` format.
Chromium uses the OS locale for native `type="date"` inputs, which is why we use a custom text format.

=== 2.1 Add Treatment modal — date-time field

Open Treatments → click *+ Treatment* → observe the *Date / Time* field.

[cols="3,2,1,1"]
|===
| Browser + OS | Format displayed | Accepted | Result

| Chrome / Linux | `dd.MM.yyyy HH:mm` | Enter `25.05.2026 14:30` | [ ] Pass [ ] Fail
| Chrome / macOS | `dd.MM.yyyy HH:mm` | Enter `25.05.2026 14:30` | [ ] Pass [ ] Fail
| Firefox / Linux | `dd.MM.yyyy HH:mm` | Enter `25.05.2026 14:30` | [ ] Pass [ ] Fail
| Safari / macOS | `dd.MM.yyyy HH:mm` | Enter `25.05.2026 14:30` | [ ] Pass [ ] Fail
|===

=== 2.2 Validation rejects invalid date strings

[cols="5,1,1"]
|===
| Input | Expected | Result

| `32.05.2026 14:30` (invalid day) | Validation error shown, form not submitted | [ ] Pass [ ] Fail
| `abc` | Validation error shown | [ ] Pass [ ] Fail
| Empty field | Validation error or defaults to now | [ ] Pass [ ] Fail
|===

== 5. Cross-Browser Divergence

Known divergence points between Chrome, Firefox, and Safari.

[cols="3,3,1,1"]
|===
| Area | Known divergence | Expected behaviour | Result

| Date-time input display | Chrome may show native date picker on `type="date"` fields (not used here) | Our `type="text"` fields look identical | [ ] Pass [ ] Fail
| SVG chart rendering | Firefox renders SVG `text` elements at slightly different offsets | Chart is readable; labels do not overlap data | [ ] Pass [ ] Fail
| Scrollbar width | macOS Safari hides scrollbars by default | Layout does not break when scrollbars are hidden | [ ] Pass [ ] Fail
| CSS `gap` in flex | All modern browsers support it | Stat tile rows render with consistent spacing | [ ] Pass [ ] Fail
| OIDC redirect handling | Safari may block third-party cookies on Keycloak redirect | Login succeeds with default SameSite=Lax cookies | [ ] Pass [ ] Fail
|===
