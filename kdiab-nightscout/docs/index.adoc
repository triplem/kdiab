Welcome to the kdiab-nightscout documentation hub.
`kdiab-nightscout` is a Nightscout API compatibility layer (v1 + planned v3) that allows
AAPS, xDrip+, and Juggluco to connect to the kdiab platform without modification.
It is an *optional* service — not started by default.

== Starting the Service

The service is declared with a Docker Compose profile and is not started by default:

[source,bash]
----
./podman-up.sh --optional --build
# or
COMPOSE_PROFILES=optional docker compose up --build
----
